Painel Admin

Entre com um token de acesso do GitHub para editar textos, shows, galeria, vídeos, notícias e a loja do site.

Fica salvo só neste navegador. Nunca compartilhe esse token com ninguém.
Não tenho um token — como eu crio um?
  1. Acesse github.com/settings/personal-access-tokens/new (é preciso estar logado no GitHub).
  2. Em Token name, dê um nome como Admin site Indefenza.
  3. Em Expiration, escolha um prazo (ex: 90 dias) — depois disso você cria um novo.
  4. Em Repository access, marque Only select repositories e escolha site-indefenza.
  5. Em Permissions → Repository permissions, ache Contents e mude para Read and write.
  6. Clique em Generate token lá embaixo.
  7. Copie o token gerado (começa com github_pat_) e cole no campo acima.
